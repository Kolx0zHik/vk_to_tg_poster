ИИ-проверка дублей

Base URL Например https://openrouter.ai/api/v1
Модель Например inclusionai/ling-3.0-flash-sante:free
Окно сравнения За сколько дней искать похожие посты.
Промпт для ИИ Только правила: что считать дублем, а что нет. Формат ответа (JSON) система задаёт сама. В свежем конфиге уже заполнен пример — отредактируйте под себя. Без промпта проверка не работает.
Ключ API задаётся в файле .env рядом с конфигом — переменная LLM_API_KEY.
